## 术语与权威口径

### 1. 真实 GOAL（Real Goal）

**定义边界**（回应第二团审计 #6，主脑裁决 B-1 采纳）：
真实 GOAL = 同时满足以下全部条件的任务：
1. **经 Runtime 黑盒真实执行**（非模拟/冒烟）；
2. **有完整 RUN 目录**：`state.json` + `msg/report/reply` 消息链齐备；
3. **R-PROD 真实会话给出终审 PASS**（reply 含 `===REVIEW_VERDICT=== PASS`）。

**排除项**：RUNNING / HARD_BLOCKED / 冒烟目录（如 `RUN-20260818-rtv1`）一律不计入真实 GOAL。

### 2. 真实 GOAL 计数（权威数字 = 累计 8 次，全部 DONE+PASS）

| 批次 | 次数 | RUN | 说明 |
|---|---|---|---|
| 第一批（流 C） | 3 | `RUN-20260829-223254-b173` / `-223925-b718` / `-224224-7cfe` | V1.0 判据"连续 3 次全绿"所指 |
| 第二批（流 C2/D） | 5 | `RUN-…-ff88` / `-41b4` / `-cfb5` / `-c33e` / `-37d9` | 恢复控制会话真实 GOAL |
| **累计** | **8（3+5）** | 上表全部 | **全部 DONE + PASS** |

**历史数字对应解释（禁止裸数字，引用时必须带口径）**：
- `8` = 累计（两批合计）；
- `5` = 第二批（恢复控制会话 5 次）；
- `4` = 收口报告快照时点少计一次；
- `3` = V1.0"连续三次"判据口径（第一批）。

**统一写法**：`累计 8 次真实 GOAL（第一批 3 + 第二批 5），全部 DONE+PASS`。

### 3. R 审查 / REWORK 轮次（权威定义）

**轮次定义**（主脑裁决 B-2）：
> 轮次 = reply 文件中 `===REVIEW_VERDICT=== REWORK` 判定计数（机器可数，无歧义）。

- 不含 `PASS` 判定、不含发送次数、不含整改动作数；
- 终审 PASS 不计入 REWORK 轮次；
- 全仓"X 轮 REWORK"类表述一律以本定义重数后的数字为准。
