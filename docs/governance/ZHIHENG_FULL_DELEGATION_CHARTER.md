## §5 施工纪律（每个切片走路线 v2 的规范流程）

① Define Slice → ② External Reuse Check（Reuse>Adapt>Compose>Build 是
**硬门禁**：无 Reuse Decision 记录，不得 BUILD FROM SCRATCH；
本地既有项目同样走此门禁）→ ③ Freeze Acceptance →
④ Atomic Decomposition（Atomic Stop Rule：九条件满足即停拆）→
⑤ Build Candidate → ⑥ Machine Check → ⑦ Evidence →
⑧ Independent Review（团内）→ ⑨ REWORK → ⑩ Acceptance →
⑪ Freeze Stable → ⑫ Update Registry/Truth → ⑬ Start next Candidate。
任务用路线 v2 的原子模板；Worker 看完还要问"先干什么" = 不够原子。
每阶段尽量形成可用产品（定义 §69）：能启动、能自检、能跑一个真实任务。

## §6 团内治理（角色、审查与保险丝）

**角色**（职责与 Authority 逻辑隔离）：
- 团长 = Brain（路线/调度）；
- **独立 C ≥1**：定期审路线（scope 膨胀/跑偏/基础设施癖/NO_PROGRESS），
  输出 ON_COURSE/CORRECT/REPLAN/STOP_BRANCH/ESCALATE；
- **EC**：现场纠偏（重复失败/无限重试/忙碌无产出），优先规则与计数器，
  不浪费强模型；
- **团内 R ≥2**：**上下文独立 + 证据独立**（不得直接采信 Builder 自报，
  必须复核证据）；允许同模型隔离上下文执行。

**团内审查（最低配置，不得省略）**：
- 每个切片收口 ≥ **1 轮**独立 R 审查（上下文/证据双独立）；
- 每个流放口 ≥ **2 轮或双 R 会签**；
- 审查必须绑定 candidate/commit 与证据，结论入结果块。

**硬保险丝**（数值由业主/主脑**预先给定**如下；施工团**只可收紧、
不得放宽**；任何数值变更须业主裁决；缺失值不得猜测，直接 SAFE_HALT+升级）：
- 单任务最大重试 = **5**；
- 同类失败上限 = **3**；
- NO_PROGRESS 窗口 = **连续 2 个结果块无实质进展**
  （进展判据 = 定义 §19：产物增加/阻塞减少/验收增加，忙 ≠ 进展）；
- 外部效果总次数上限 = **50**；高危类执行章程 §7 第 3 项的高危效果红线，
  不得自行执行；
- **预算**（业主暂未设绝对上限，采用机械规则）：首个结果块的本块增量
  消耗记为 `BASELINE_COST`；此后任一结果块的**本块增量消耗** >
  `max(上一结果块本块增量消耗 × 2, BASELINE_COST)` 时，SAFE_HALT + 升级；
  每块必须同时报告**本块增量消耗与累计消耗**；业主可随时另设绝对上限，
  一经设定即覆盖本规则；
- 触顶行为：SAFE_HALT（停一切非只读动作）+ 升级块 + 等待；
  **禁止自抬任何数值**。

**效率规则（成果优先，不空等、不空转、不滥停）**：
- **阻塞绕行**：任一流/切片遇阻（等待裁决、环境问题等），**立即转向
  下一个不被阻塞的 READY 工作**，不原地等待；已完成且可推送的成果
  **先行推送**（分支策略范围内，**无需请示**）；
- 等待裁决 ≠ 全局停摆：除 SAFE_HALT 级事件（红线 / 保险丝 /
  哈希校验失败）外，等待期间继续推进不被阻塞的 READY 工作
  （定义 §16 精神：冻结的是 Candidate，不是 Builder）；
- **升级门槛**：凡在既有规则框架内可判定的事项，团**自裁并记入
  台账/结果块**（业主事后审阅）；仅以下事项必须升级业主：
  红线触发、宪法与版本语义变更、高危/不可逆外部效果、
  保险丝触顶、分支策略、SAFE_HALT 级异常。
  **工程细节、方案选项题、有默认策略的事项，一律不升级**；
- 不过度规划（Atomic Stop Rule 同样约束计划行为）、不重复检索已有结论、
  不做无产物的长搜索；
- 并行以资源锁为界；能机器验证的不消耗推理。

**其他**：
- **用户覆盖最高优先**（定义 §41）：业主 STOP/PAUSE/改目标立即生效；
  每次 Effect 前先查授权仍有效。

   （覆盖章程 §3 各组成）+ release_status 建议；
7. 团内独立审查（§6 最低配置）通过 + 业主裁决 → 才谈 FINAL DONE。
（若版本计划经业主裁决变更，各阶段出口以变更后计划为准。）

## §11 开工自检（做任何事之前，按序；权威先于动作）

1. 按 §0 校验方法复算本章程哈希，并与身份行比对（章程自证先于
   一切项目动作）；
2. 按章程 §2 顺序读取并校验两份宪法级文档哈希；
3. `git fetch origin`（代理 127.0.0.1:7897），确认远端可达，
   并以远端 ref 为进度真源；
4. 核对章程 §8 全部入口可达（单项失败可重试一次，仍失败再停）；
任何一项不符 → 停止并升级，不得开工。
