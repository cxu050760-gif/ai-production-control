## Authority Monotonic Recovery Rule

以下状态不能因为 snapshot rollback 倒退：

```text
REVOKED → ACTIVE

CONSUMED → AVAILABLE

tightened Goal Contract → older broader Goal Contract authority

newer security policy generation → older weaker generation

newer Worker trust restriction → older broader authority

newer revocation epoch → older epoch

newer Controller TCB generation → stale verification generation
```

特别是：

```text
revocation
consumption
scope tightening
```

一旦 durable commit：

不能因为 State Revision rollback 被撤销。

---

## Canonical State Recovery 最终顺序

必须：

```text
recover latest known-good Canonical State
↓
scan Effect WAL
↓
scan AUTHORITY_COMMIT_JOURNAL
for authority events newer than recovered snapshot
↓
replay/reconstruct latest durable authority state
↓
verify:

  authorization generation
  revocation epoch
  consumed authorization capacity
  Goal Contract security-relevant generation
  security policy generation
  Worker trust generation
  Controller TCB verification generation

↓
reconcile unresolved Effect WAL attempts
↓
commit recovered coherent Canonical State revision
↓
only then permit new production effects
```

```text

```

## Goal Contract Tightening Special Rule
