## 审核三：定义节证据 — **PASS**
- **§56 多 Worker 并行**（L1773-1786）：系统必须知道谁执行什么/输入输出/修改哪些资源/是否冲突/是否值得并行——并发分派（`max_concurrent`）+ 任务资源声明 + 结果对应 ✓
- **§57 Resource Lock/Isolation**（L1789-1813）：同一文件/branch/session/account 不能被冲突 Worker 无控制同时修改——`ResourceLockManager`（每资源 mkdir 原子互斥 + 冲突排队 `LOCK_WAITING` 不失败）✓
- **§58 Project Isolation**（L1816-1832）：Project A 不得污染 Project B——每任务独立 work_dir + 越界写校验 + **symlink 逃逸扫描** ✓
- **§16 WAIT 局部性**（L660-685）：A=WAITING 时执行 B/C——`LOCK_WAITING`/`WAIT` 不阻塞其余 READY 任务 ✓
- **§23 用户目标变化使旧执行权失效**（L902-920）：改 Goal/缩 Scope/STOP/撤销权限 → 旧 Worker 不得继续按旧状态执行——STOP/REVOKE directive → REVOKED + 后续结果拒收 ✓
- **§40 Authorization Revocation 单调性**（L1379-1397）：撤销/STOP 不能因状态回滚而复活——epoch 单调递增 + 回滚/复活低 epoch 拒绝（`STALE_EPOCH`）✓
- **§41 User Override 最高优先级**（L1400-1412）：STOP/PAUSE/CHANGE GOAL/REVOKE 为最优先控制事件——REVOKED_EPOCH 拒收被撤销代结果 ✓
- **§30 Stale Result Safety**（L1108-1136）：Material Change 后旧结果失效——心跳超时 → `STALE` 回收 + `STALE_HEARTBEAT` 拒收 + 释放资源锁 ✓
- **§38 OUTCOME_UNKNOWN 与 Reconciliation**（L1323-1350）：结果不明不能立刻重试，必须 RECONCILE/Inspect Reality/Decide Retry——`OUTCOME_UNKNOWN` + `decision_entry=MANUAL_OR_RETRY`（不自动判定成败）✓
